# Privacy

This site collects very little. I do not run accounts, newsletters, payments, or my own visitor database.

**Not collected or stored by me:** IP addresses, login credentials, payment details, or browsing history outside what third parties below may process on their own.

- **Contact form** — [Formspree](https://formspree.io/legal/privacy-policy) delivers your name, email, and message. Used only to reply.
- **Meeting booking** — the [Cal.com](https://cal.com/privacy) link on the contact page works like the form: if you book, Cal.com receives what you enter there (e.g. name, email). This site only links to it.
- **Hosting** — [GitHub Pages](https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement) logs each request: IP address, browser, page URL, and time. I do not receive these logs; GitHub does.
- **Theme** — light/dark choice saved only in your browser (`localStorage`); not sent to any server.
- **Analytics** — [GoatCounter](https://www.goatcounter.com/help/privacy) (EU-hosted) counts page views, referrer, browser and country. No cookies, no tracking of individual visitors.
- **Cookies, trackers** — none. Fonts are served from this site, not from Google.

Questions? [Contact me](/contact/).

# Confidentialité <span aria-hidden="true">🇫🇷</span>

Ce site collecte très peu de données. Pas de comptes, newsletter, paiement ni base visiteurs de mon côté.

**Non collecté ni stocké par moi :** adresses IP, identifiants, données de paiement, ni historique de navigation au-delà de ce que les tiers ci-dessous peuvent traiter de leur côté.

- **Formulaire** — [Formspree](https://formspree.io/legal/privacy-policy) transmet nom, e-mail et message. Utilisés uniquement pour répondre.
- **Prise de rendez-vous** — le lien [Cal.com](https://cal.com/privacy) sur la page contact, comme le formulaire : si vous réservez, Cal.com reçoit ce que vous y saisissez (nom, e-mail, etc.). Ce site ne fait que pointer vers ce service.
- **Hébergement** — [GitHub Pages](https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement) enregistre chaque requête : IP, navigateur, URL, heure. Je n’ai pas accès à ces journaux ; GitHub oui.
- **Thème** — choix clair/sombre uniquement dans votre navigateur (`localStorage`) ; rien n’est envoyé au serveur.
- **Statistiques** — [GoatCounter](https://www.goatcounter.com/help/privacy) (hébergé dans l’UE) compte les pages vues, le site d’origine, le navigateur et le pays. Sans cookies ni suivi individuel.
- **Cookies, traceurs** — aucun. Les polices sont servies par ce site, pas par Google.
